Deploy Next.js site to GitHub pages

First run this command to VS code terminal

==> npm install gh-pages --save-dev

In package.json file look at the devDependencies see gh-pages are added or not.

==> 

  "devDependencies": {
    "@types/react": "^19.2.18",
    "@types/react-dom": "^19.2.4",
    "@vitejs/plugin-react": "^6.1.0",
    "gh-pages": "^6.3.0",
    "oxlint": "^1.79.0",
    "vite": "^8.2.2"
  }

Add homepage on your package.json file

==>

"name": "3d-website",
"private": true,
"version": "0.0.0",
"type": "module",
"homepage": "https://your-github-username.github.io/your-repo-name",

Add predeploy and deploy in your scripts like this

==> 

  "scripts": {
    "predeploy": "npm run build",
    "deploy": "gh-pages -d out",
    "dev": "vite",
    "build": "vite build",
    "lint": "oxlint",
    "preview": "vite preview"
  }

Open your next.config.ts and paste this 

==>

import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  output: "export",
  basePath: "/your-repo-name",
  images: {
    unoptimized: true, // Required if you are using the next/image component in a static export
  },
};

export default nextConfig;


In Public folder create a .nojekyll file 


Run this command ==> npm run build


Then push all your files and folder to GitHub.

After pushing all this files to GitHub.

Go to your repository on GitHub.com and navigate to Settings > Pages.
Under the "Build and deployment" section, select Deploy from a branch as the source.
In the branch dropdown menu, select the gh-pages branch, leave the folder as / (root), and click Save.
